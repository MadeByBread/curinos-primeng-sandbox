Curinos Tokens

--curinos-* custom properties generated from Figma collection exports. This is the only token layer — component overrides consume these directly, with no bridge in between. For how each component uses them, see the Component catalogue.

Figma export format

The generator expects the rich export format from Figma variable collections — not the flat token list. Each source file is one collection with variables[], mode definitions, and resolved alias chains.

  • Top-level: name, modes, variables[]
  • Per variable: name, type, resolvedValuesByMode with resolvedValue and optional aliasName

Source file mapping

One Figma collection export maps 1:1 to one generated SCSS partial under src/styles/tokens/sources/.

Source file Figma collection Generated partial CSS prefix Count
curinos-colors.json Curinos Colors _color.scss --curinos-color-* 372
curinos-dimensions.json Curinos Dimensions _dimensions.scss --curinos-dimensions-* 20
curinos-effects.json Curinos Effects _effects.scss --curinos-effects-* 10
curinos-typography.json Curinos Typography _typography.scss --curinos-typography-* 20

Colors ship Light and Dark; the other three collections are single-mode. Chart colors (data/chart/*) are now real Figma variables rather than a merged sidecar.

Generator rules

scripts/figma-tokens-to-scss.js is collection-driven. Re-run via npm run tokens:build.

  • Collection-driven — one JSON file → one SCSS partial
  • Both modes emitted — Light fills :root, Dark fills [data-theme="dark"]. The dark block carries only the tokens that genuinely differ: an alias pointing at the same target in both modes re-resolves on its own once that target is overridden
  • Alias inheritance — same-collection aliases become var(--curinos-…-<alias>, <literal>)
  • Naming — full Figma path slugged to kebab-case (semantic/surface/50 → --curinos-color-semantic-surface-50)
  • Type formatting — colors → hex; floats → px except font weights and line heights; opacity/* is rescaled from Figma's 0-100 to CSS's 0-1; font families → quoted stack
